## Preface

I'll be primarily comparing __stock__ software, without any of their fancy account features. They both offer cloud storage but reMarkable requires a subscription, whilst Supernote does not at the time of writing this.

My reMarkable tablet is refurbished, and seems to have 2 dead pixels. I have also contacted both Supernote and reMarkable in the past about pen accuracy issues, neither of the issues was resolved.

(actually, remarkable did get back to me finally and offer a replacement, but I decided to return the device instead)

(at the time of posting this review, my device has already been returned, I could not stand using it the whole month I planned on keeping it, lasted only 4 days)

The reMarkable tablet was also returned only a week after getting it, I actually just couldn't get through the entire month I planned on keeping the device, it completly ruined my workflow at work.

## reMarkable

### The good

- Accessories
    - Pen with eraser
    - More cover options (I like the leather one)
- Display
    - Larger
    - Color
    - Backlight
- System
    - Linux
    - Encrypted file system
    - Responsive
    - Better gesture recognition
- UI
    - Good tagging system
    - Nicer and simpler interface design
- Hardware
    - Leather for cover and metal for body
    - Feels much more sturdy being all metal and glass
- Misc
    - 50 day try-out with full refund and free returns
    - Customer support was responsive and good in my experiance, offered a replacement for my pen issues, but I opted for returning the device

### The bad

- Pen
    - Poor pen accuracy
    - Needs charging
    - Cannot use 3rd party pens
    - Only 2 options
    - Nibs wear out fast
    - Nibs are expensive
- System
    - File transfer over us is a bit annoying, only over web interface that times out on large file moves
    - Not many pen settings, only 3 levels of thickness
    - Many features locked to needing a "Connect" account
        - Text recognition
        - Sending files over email
    - Cannot set custom sleep screens
    - Cannot set PDF or Epub contrast
    - Cannot view 2 pages side by side when in landscape (This is more of a wish it had it, rather than a complaint, I dont think the Supernote Manta can do this either)
    - Can only open notes, PDFs and Epubs, not even image files
    - Changing settings in PDFs and Epubs is horrily slow
    - Cannot connect to webDav or self-host cloud (supernote allows that out of the box)
    - Selfhosting possible but difficult
    - Any changes to the file system get wiped after every system update
    - Running external apps, like a browser to display web pages, is not possible or easy to get running due to how the display drivers work
- Hardware
    - Very poor battery life (3.5 days in my usage)
    - Heavy af, to the point Im scared to carry it around with me
    - Lack of repairability (Thought, they offer refurbished devices, Supernote doesnt do that to my knowledge)
    - Whilst feeling sturdy, it does feel scary to carry, due to how prestine it looks and feels, supernote Im not scared to chuck into my backpack as long as the screen-side is protected
- Display
    - Refreshed a lot (doesnt bother me, but bothered everyone else that used the device)

## Supernote

### The good

- Pen
    - Standard Wacom EMR (?) Pen
    - Comes with DIY kits to make your own pens
    - Plenty of choices for stock pens
    - Better pen accuracy
    - No need of replacing nibs
- System
    - Built-in WebDAV support (Nextcloud works amazingly !!!!)
    - Built-in support for running a private intance of their cloud
    - All features work offline
    - Better pen options
    - Much better file transfer over USB, as standard Android device
    - Many useful options for adjusting how PDFs are rendered, cropping, contrast etc
    - Can open many more formats on the device, including various documents and images
    - Better support for sideloading apps, as it is just Android
- Hardware
    - Faster screen refreshing
    - Amazing battery life, almost 2 weeks on my usage
    - Very repairable, with ability to buy replacement batteries and motherboards
    - Expandable storage
    - supernote comes with a right-angled usb-c cable, which is a very nice touch
- Misc
    - Much better communiaction with the community

### The bad

- Android
    - Comes with many upsides, but they seem to be behind on updating Android and CVEs
    - Not an encrypted file system, no different than having an open notebook on your desk, (though on their todo list)
- System
    - Not responsive
    - Slow at opening larger notes
    - Not a polished experience, sometimes many menus or options crammed
    - File management on the device itself is clunky and not particuarly well done (cannot change capitalization in file names for example)
- Cloud
    - Self hosted server closed source
    - WebDav push and pull system for file changes, works the same as external sources on reMarkable, but wish there was a slightly more efficient system with this
- Hardware
    - supernote build quality not that amazing
    - supernote does not feel that sturdy
    - the supernote feelwrite screen changes texture depending on room temperature (more gooey in the summer)
